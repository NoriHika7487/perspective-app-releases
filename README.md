# パースのアプリ（Windows）

このページは、**インストーラーを置くための場所**です。プログラム本体は別の非公開の場所にあります。

## 入れ方

1. 右の「Releases」から、いちばん新しい `PerspectiveApp-Setup-x.y.z.exe` を落とします。
2. ダブルクリックします。「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押します。
   （発行元の証明書をまだ付けていないため、この知らせが出ます）
3. 「インストール」→「完了」と進みます。

## 更新

入れたあとは、アプリを開いたときに新しい版があるかを自分で見に行きます。
見つかると「新しい版があります」と出るので、「更新する」を押すだけです。
